
## 2025-05-15 - Accessible Semantic Components & Focus Visibility
**Learning:** Using semantic `<button>` elements instead of `<div>` for interactive components (like cards and tabs) significantly improves the out-of-the-box keyboard experience and screen reader compatibility. Global `:focus-visible` styles ensure that keyboard users always have a clear visual indicator of where they are in the interface.
**Action:** Always prefer semantic interactive elements and implement a high-contrast `:focus-visible` outline in the global design system.
