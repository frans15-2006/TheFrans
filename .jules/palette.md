
## 2026-06-04 - Semantic Tabs and Live Regions for E-commerce
**Learning:** Using semantic `<button>` elements with `role="tab"` and `aria-selected` provides a much better experience for keyboard and screen reader users than generic `div` tabs. Additionally, `aria-live="polite"` on cart regions ensures that dynamic price and item updates are announced without interrupting the user's flow.
**Action:** Always prefer semantic buttons for interactive elements and use live regions to announce asynchronous UI updates in shopping carts or dashboards.
