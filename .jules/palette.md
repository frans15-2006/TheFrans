## 2025-05-16 - Semantic Buttons for Interactive Elements
**Learning:** Converting `div`-based interactive elements like category tabs and product cards to semantic `button` elements provides native keyboard support (focusability and 'Enter'/'Space' activation) but requires a CSS reset for `background`, `border`, and `font` to maintain visual consistency with the original design.
**Action:** Prioritize semantic HTML elements over `div`s with click handlers, and ensure a global or component-specific CSS reset is applied to maintain the UI's aesthetic.
