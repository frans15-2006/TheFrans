## 2026-05-12 - [Semantic Buttons & Dynamic ARIA Labels]
**Learning:** Converting `div`-based interactive elements (like food cards or category tabs) to semantic `button` elements is essential for keyboard accessibility. However, it requires a careful CSS reset for background, border, font, and text alignment to ensure visual consistency with the original design. Additionally, providing dynamic `aria-label` attributes that include contextual data (e.g., item price) significantly improves the shopping experience for screen reader users.
**Action:** Always prefer semantic `<button>` or `<a>` elements for interactive components. Implement a global button reset in CSS when migrating from non-semantic elements, and use template literals to build descriptive, data-rich ARIA labels.
