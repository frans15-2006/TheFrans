## 2026-05-28 - Layout Thrashing and Scroll-Resilient Caching
**Learning:** Calling `getBoundingClientRect()` inside a `mousemove` listener triggers synchronous layout calculation, causing layout thrashing. While caching the rectangle on `mouseenter` or `resize` solves this, using viewport-relative coordinates (`e.clientX`, `e.clientY`) against a cached rectangle fails if the page is scrolled while the mouse is inside the element.
**Action:** Always cache bounding rectangles outside of high-frequency listeners. To ensure scroll-resiliency, convert the cached viewport coordinates to document-relative (absolute) coordinates by adding `window.scrollX` and `window.scrollY`. Use `e.pageX` and `e.pageY` in the listener to match these absolute coordinates, maintaining both performance and accuracy regardless of scroll position.
