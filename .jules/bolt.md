## 2025-05-19 - Optimization of High-Frequency Animations and Asset Loading
**Learning:** High-frequency animations (custom cursors, scroll progress) using layout properties (`top`, `left`, `width`) cause significant layout thrashing. Refactoring these to use GPU-accelerated transforms (`translate3d`, `scaleX`) significantly improves frame rate stability. Additionally, decoupling expensive style updates (like the cursor `glow`) from the `mousemove` event and moving them into a `requestAnimationFrame` loop reduces redundant work.
**Action:** Always prefer `transform` and `opacity` for animations. Ensure high-frequency updates are throttled or managed via `requestAnimationFrame`. Use `loading="lazy"` and `decoding="async"` for large non-critical assets to optimize initial load.
