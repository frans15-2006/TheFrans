About

Who I Am

I'm a BSIT student from Palawan, Philippines, studying at Palawan Technological College, Inc. I build web applications with a strong focus on the backend — how data flows, how systems scale, and how things work under the hood.

My approach is straightforward: understand the problem first, then build the right solution. I care about code that's readable, maintainable, and actually works — not just code that looks impressive.

When I'm not coding, I'm exploring local AI deployments, tuning hardware, and figuring out how to run powerful tools in low-resource environments.
