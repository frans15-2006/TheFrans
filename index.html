Android App · Jetpack Compose 2026

VOLT

A smart home energy operations platform for Android. Monitor, control, and automate every electrical outlet in a home from one interface — room-based dashboards, real-time wattage tracking, fire/overheat detection with emergency shutdown, and an interactive floor plan built for smooth 120–144 Hz motion. Six screens (Dashboard, Automation, Insights, Outlet Detail, Copilot, Settings) run on an MVVM architecture with a Room-backed local database as the single source of truth.

Under the Hood
Every outlet toggle writes an event log with a computed wattage delta — manual overrides are tracked separately from automation so scheduled actions never silently clobber a user's manual state.
Floor plan pins are stored as normalized X/Y percentages per outlet, so the layout stays correct across any screen size without hardcoded coordinates.

Open Source Contribution · WPF 2026

FluentFlyout

Contributed to unchihugo/FluentFlyout, an open-source Fluent 2 Design flyout utility for Windows 11. Refactored duplicated taskbar and marquee update logic scattered across property change handlers into two shared helper methods, and hardened the saved-language restore path so a missing or invalid language tag falls back gracefully instead of crashing the app on launch.

Under the Hood
Consolidated repeated taskbar/marquee state updates into UpdateTaskbar() and UpdateTaskbarMarquees() helpers, with null-safe access to MainWindow and widget instances — no behavior change, no new user-facing features.
Replaced a throwing .First() lookup in the app-language restore path with a cascading fallback (exact match → system default → first available), logging a warning whenever a fallback occurs.
